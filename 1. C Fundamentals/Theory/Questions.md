# C - Fundamentals 

1. What is an algorithm? Explain the properties of a good algorithm.
2. Describe preprocessing, compilation, assembly, linking, and loading.
3. Draw and explain the general structure of a C program.
4. Differentiate syntax, semantic, linker, runtime, and logical errors.
5. Explain keywords, identifiers, literals, variables, constants, declarations, and definitions.
6. Compare fundamental C data types and explain sizeof.
7. Explain signed and unsigned integers, integer ranges, overflow, and type conversion.
8. Explain arithmetic, relational, logical, assignment, conditional, and bitwise operators.
9. Explain operator precedence and associativity with examples.
10. Compare if/else, switch, for, while, and do-while.
11. Explain break, continue, and goto, including risks of overuse.
12. Compare printf, scanf, getchar, putchar, fgets, and puts.
13. Explain scope, lifetime, and storage classes: auto, static, extern, and register.
14. Explain command-line arguments using argc and argv.
