## Question 

What is an algorithm? Explain the properties of a good algorithm.

## Answer 

An algorithm is a step-by-step set of finite, well-defined instructions designed to solve a specific problem or perform a computation. It is independent of any programming language and acts as a blueprint for writing code. 

### Core Properties of a Good Algorithm

A reliable and effective algorithm must satisfy the following key characteristics:

* Input: An algorithm accepts zero or more well-defined inputs, specifying the type, format, and quantity of data required.
* Output: An algorithm must produce at least one well-defined output that represents the solution to the given problem.
* Definiteness (Unambiguousness): Every single instruction or step must be crystal clear and leave no room for multiple interpretations.
* Finiteness: The algorithm must always terminate or come to a stop after executing a finite number of steps (no infinite loops or endless recursion).
* Effectiveness: The operations must be basic, practical, and simple enough that they can be carried out using available resources.
* Correctness: The algorithm must yield the right and expected output for every valid set of input values.
* Efficiency: It should use minimal computational resources, specifically runtime (time complexity) and memory (space complexity).
* Language Independence: The instructions must be general and conceptual enough to be implemented in any programming language.
