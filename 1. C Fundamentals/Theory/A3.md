## Question 

Draw and explain the general structure of a C program.

## Answer 

The basic structure of a C program consists of six major sections arranged in a logical sequence to ensure efficient compilation and execution. While only the main() function is strictly mandatory, following this standard template maximizes code readability and modularity.

### Visual Block Representation

├────────────────────────────────────────────────────────┤

### Detailed Section Explanations

   1. Documentation Section
   * Purpose: Provides meta-information about the program (e.g., author, date, purpose).
      * Implementation: Uses single-line comments (//) or multi-line comments (/* ... */). The compiler completely ignores this section. 
   2. Link / Preprocessor Section
   * Purpose: Instructs the compiler to pull in required code blocks from the system library before compilation.
      * Implementation: Commences with the #include directive (e.g., #include <stdio.h> for standard input/output functions like printf). 
   3. Definition Section
   * Purpose: Declares symbolic constants or macros globally.
      * Implementation: Employs the #define preprocessor directive (e.g., #define PI 3.14159). Any reference to the macro name is instantly swapped with its defined value during preprocessing. 
   4. Global Declaration Section
   * Purpose: Declares variables and function blueprints (prototypes) that need to be visible across the entire program.
      * Implementation: Placed outside all functions. Variables declared here maintain state throughout the lifetime of the program execution. 
   5. main() Function Section
   * Purpose: Acts as the mandatory entry point where execution begins.
      * Implementation: Enclosed in curly braces {}. It is divided into two distinct internal parts:
      * Declaration Part: Where local variables inside the function are defined.
         * Execution Part: Where the actual logical operations, loops, expressions, and function calls are computed. Every statement inside this section must conclude with a semicolon (;).  
      6. Subprogram Section
   * Purpose: Houses the physical implementation of custom, user-defined functions.
      * Implementation: Written separately from the main() function block. These functions are explicitly invoked within the main() block whenever modular blocks of code need to be executed.
   
### Clean Structural Code Example

<pre>C
<code>
/**
 * 1. DOCUMENTATION SECTION
 * File: area_calc.c
 * Purpose: Computes the area of a circle to showcase structural flow.
 */
// 2. LINK / PREPROCESSOR SECTION#include <stdio.h> 
// 3. DEFINITION SECTION#define PI 3.14159 
// 4. GLOBAL DECLARATION SECTIONfloat calculateArea(float radius); float global_output = 0.0;
// 5. MAIN FUNCTION SECTIONint main(void) {
    // Local variable declaration
    float input_radius = 5.0; 
    
    // Executable programming logic
    global_output = calculateArea(input_radius);
    
    printf("The total area is: %.2f\n", global_output);
    
    return 0; // Signals successful termination
}
// 6. SUBPROGRAM SECTION (User-defined function)float calculateArea(float radius) {
    return PI * radius * radius;
}
</code>
