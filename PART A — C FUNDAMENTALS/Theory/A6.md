## Question 

Compare fundamental C data types and explain sizeof.

## Answer 

In C programming, fundamental data types are the built-in building blocks used to store numbers, characters, and fractional values. Because C is a platform-dependent language, the exact memory allocated for these types depends entirely on the underlying hardware architecture and compiler. 

### Comparison of Fundamental C Data Types
The table below breaks down the primary data types on a typical modern 64-bit architecture: 

| Data Type | Category | Typical Size | Format Specifier | Purpose & Common Use Case |
|---|---|---|---|---|
| char | Character / Integer | 1 Byte | %c | Stores single letters, symbols, or small integers (-128 to 127). |
| int | Integer | 4 Bytes | %d or %i | Stores whole numbers without decimals (e.g., counters, loops). |
| float | Floating-point | 4 Bytes | %f | Stores single-precision fractional numbers (accurate up to ~7 decimal places). |
| double | Floating-point | 8 Bytes | %lf | Stores double-precision fractional numbers (accurate up to ~15 decimal places). |
| void | Empty | 0 Bytes | N/A | Represents the absence of a value (typically used for function return types or generic pointers). |

### Type Modifiers
You can alter the range and size of integer and character data types using qualifiers: 

* signed / unsigned: signed allows both positive and negative values (default). unsigned forces the type to only hold positive numbers, doubling its upper limit.
* short / long: Adjusts the scale of storage. For example, a short int takes 2 bytes, while a long long int takes 8 bytes.  

### What is the sizeof Operator?
The sizeof operator is a unary compile-time operator used to compute the exact size (in bytes) of a data type, variable, array, or structure. 
### Core Features:

   1. Platform Independence: Since data type sizes vary across different processors (e.g., 16-bit vs 64-bit), sizeof ensures your code remains portable by evaluating the precise memory footprint dynamically at compile time. 
   2. Return Type (size_t): The operator evaluates to an unsigned integer type alias called size_t. When printing a sizeof expression via printf(), the correct format specifier is %zu. 
   3. Flexible Arguments: It can accept data types directly, variable instances, or even evaluated expressions. 

## Code Example

<pre>C
<code>
#include <stdio.h>
int main() {
    int age = 25;
    double price = 19.99;
    int numbers[5];

    // 1. Using sizeof with a Data Type
    printf("Size of int type: %zu bytes\n", sizeof(int)); // Outputs: 4

    // 2. Using sizeof with a Variable
    printf("Size of variable 'price': %zu bytes\n", sizeof(price)); // Outputs: 8

    // 3. Finding Array Lengths
    // Total array size (5 elements * 4 bytes = 20) divided by a single element (4 bytes)
    size_t length = sizeof(numbers) / sizeof(numbers[0]);
    printf("Number of elements in array: %zu\n", length); // Outputs: 5

    return 0;
}
