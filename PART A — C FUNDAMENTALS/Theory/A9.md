## Question 

Explain operator precedence and associativity with examples.

## Answer 

Operator precedence and associativity are rules in programming languages that determine how an expression is parsed and evaluated when it contains multiple operators. 

### 1. Operator Precedence
Operator precedence determines which operator is evaluated first in an expression that contains different types of operators.

* Operators with higher precedence are evaluated before operators with lower precedence.
* You can use parentheses () to override default precedence and explicitly control the evaluation order. 

### Example of Precedence

int res = 10 + 20 * 30;

* How it evaluates: The multiplication operator (*) has higher precedence than the addition operator (+). 
* Step-by-Step:
1. 20 * 30 is evaluated first $\rightarrow `600`$
   2. 10 + 600 is evaluated next $\rightarrow `610`$ 
* Result: 610 (not 9000 from (10 + 20) * 30) 

### 2. Operator Associativity
Operator associativity decides the direction of evaluation (left-to-right or right-to-left) when an expression contains multiple operators of the same precedence level.

* Left-to-Right Associativity: Operations are grouped and processed starting from the left side and moving toward the right (common for arithmetic like +, -, *, /). [3, 4] 
* Right-to-Left Associativity: Operations are grouped and processed starting from the right side and moving toward the left (common for assignment = or ternary ?: operators). 

### Example 1: Left-to-Right Associativity (Division and Modulus)

int res = 100 / 5 % 2;


* How it evaluates: / and % share the same precedence level, and their associativity is left-to-right. [1] 
* Step-by-Step:
1. 100 / 5 is evaluated first $\rightarrow `20`$
   2. 20 % 2 is evaluated next $\rightarrow `0`$
* Result: 0

### Example 2: Right-to-Left Associativity (Assignment)

int a, b, c;
a = b = c = 5;


* How it evaluates: Assignment operators (=) have right-to-left associativity. 
* Step-by-Step:
1. c = 5 assigns 5 to c
   2. b = (c = 5) assigns the result to b
   3. a = (b = 5) assigns the result to a 
* Result: All three variables (a, b, and c) equal 5.

### Quick Reference Table (C / Common Languages)

| Precedence Level (High to Low) | Operators | Associativity |
|---|---|---|
| 1 (Highest) | (), [], ->, . | Left-to-right |
| 2 | Unary ++, --, !, ~, *, & | Right-to-left |
| 3 | *, /, % | Left-to-right |
| 4 | +, - | Left-to-right |
| 5 | Relational <, <=, >, >= | Left-to-right |
| 6 | Equality ==, != | Left-to-right |
| 7 | Logical AND (&&) | Left-to-right |
| 8 | Logical OR ({|}) | Left-to-right |
| 9 | Conditional (?:) | Right-to-left |
| 10 (Lowest) | Assignment (=, +=, -=, etc.) | Right-to-left |
