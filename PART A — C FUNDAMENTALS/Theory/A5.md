## Question 

Explain keywords, identifiers, literals, variables, constants, declarations, and definitions.

## Answer 

In programming languages (like C or C++), these fundamental terms describe the basic building blocks of code structure, syntax, and data storage. 
### Keywords

* Definition: Reserved, pre-defined words that have a special, fixed meaning in the programming language.
* Rules & Role: They control program flow or define data types (e.g., int, if, else, return, while). You cannot use them as custom names or identifiers.

### Identifiers

* Definition: User-defined names given to program elements such as variables, functions, arrays, or classes.
* Rules & Role: They make code readable and help the compiler track each element uniquely. They must start with a letter (A-Z, a-z) or an underscore (_), can contain digits and underscores, and cannot match a keyword. Names are case-sensitive.

### Literals

* Definition: Fixed, constant data values written directly into the source code.
* Rules & Role: They represent raw values that do not change during execution (e.g., the integer 42, the floating-point number 3.14, the character 'A', or the string "Hello"). 

### Variables

* Definition: Named memory locations used to store data that can change or be modified during program execution.
* Rules & Role: Every variable is an identifier. It has a data type (such as integer or float) and holds a value that can be updated later in the code (e.g., int score = 10;). 

### Constants

* Definition: Fixed values or memory locations whose values cannot be altered once they are set.
* Rules & Role: You create them either by using a preprocessor directive (like #define) or by prefixing a variable with a qualifier like const (e.g., const int MAX_USERS = 100;). 

### Declarations

* Definition: A statement that introduces an identifier (such as a variable or function) to the compiler along with its data type.
* Rules & Role: It tells the compiler what type of data the identifier will hold, without necessarily assigning an initial value or allocating runtime storage depending on the context (e.g., int count;). 

### Definitions

* Definition: A statement that actually allocates memory for a variable or writes the full body and logic for a function.
* Rules & Role: While a declaration says "this name exists and has this type," a definition says "here is the actual storage or implementation for it" (e.g., int count = 10; both declares and defines count).
