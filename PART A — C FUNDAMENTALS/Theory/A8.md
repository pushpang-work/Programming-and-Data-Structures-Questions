## Question 

Explain arithmetic, relational, logical, assignment, conditional, and bitwise operators.

## Answer 

Operators are special symbols used in programming to perform calculations, compare values, manipulate data, and control the flow of a program. They act on variables and constants, which are referred to as operands. 
The table below provides a direct comparison and summary of the six core categories of operators:

| Operator Category | Common Symbols | Primary Function | Evaluation / Output |
|---|---|---|---|
| Arithmetic | +, -, *, /, %, ++, -- | Mathematical calculations | Numeric value |
| Relational | ==, !=, >, <, >=, <= | Value comparison | Boolean (true/false or 1/0) |
| Logical | &&, ||, ! | Boolean condition evaluation | Boolean (true/false or 1/0) |
| Assignment | =, +=, -=, *=, /=, %= | Storing or updating data | Modifies the left-hand variable |
| Conditional | ? : | Inline choice making (Shorthand if-else) | Evaluates to one of two expressions |
| Bitwise | &, |, ^, ~, <<, >> | Manipulating data at the binary level | New integer pattern of binary bits |

## 1. Arithmetic Operators
Used to perform standard mathematical equations.

* + (Addition): Adds two values (e.g., 5 + 3 equals 8).
* - (Subtraction): Subtracts the right value from the left value (e.g., 5 - 3 equals 2).
* * (Multiplication): Multiplies two values (e.g., 5 * 3 equals 15).
* / (Division): Divides the left value by the right value (e.g., 6 / 3 equals 2). Note: In many languages, integer division truncates decimals (e.g., 5 / 2 equals 2). 
* % (Modulus): Returns the remainder of a division operation (e.g., 5 % 2 equals 1). 
* ++ / -- (Increment/Decrement): Unary operators that increase or decrease a variable's value by 1. Can be used as prefix (++x) or postfix (x++). 

## 2. Relational (Comparison) Operators
Used to test the relationship between two operands. They always output a true or false state. 

* == (Equal to): Checks if the values are identical (e.g., 5 == 5 is true). Do not confuse with the single = assignment operator.
* != (Not equal to): Checks if the values are different (e.g., 5 != 3 is true).
* /> / <: Checks if the left side is strictly greater than or less than the right side.
* />= / <=: Checks if the left side is greater than/less than or equal to the right side. 

## 3. Logical Operators
Used to combine multiple relational expressions or invert a boolean state.  

* && (Logical AND): Returns true only if both conditions are true (e.g., 5 > 3 && 2 < 4 is true). Uses short-circuit evaluation: if the first condition is false, the second is skipped. 
* || (Logical OR): Returns true if at least one condition is true (e.g., 5 > 10 || 2 < 4 is true). Uses short-circuit evaluation: if the first condition is true, the second is skipped. 
* ! (Logical NOT): Reverses the boolean state of the expression (e.g., !(5 > 3) evaluates to false).

## 4. Assignment Operators
Used to assign values to variables. 

* = (Simple Assignment): Assigns the right-side value directly to the left-side variable (e.g., x = 10).
* Compound Assignments (+=, -=, *=, /=, %=): Shorthand combinations that perform an arithmetic operation and assign the result back to the original variable. For example, x += 5 is identical to writing x = x + 5. 

## 5. Conditional (Ternary) Operator
The only operator that requires three operands (condition ? expression_if_true : expression_if_false). It functions as a single-line compact alternative to an if-else statement. 

* Example: int max = (a > b) ? a : b;
* If a > b is true, the value of a is assigned to max.
   * If a > b is false, the value of b is assigned to max. 

## 6. Bitwise Operators
Used to execute operations on numbers at the individual bit level (binary sequence of 1s and 0s). These are vital for low-level systems programming and hardware interaction. 

* & (Bitwise AND): Pairs bits and returns 1 if both bits are 1.
* | (Bitwise OR): Pairs bits and returns 1 if at least one bit is 1.
* ^ (Bitwise XOR): Pairs bits and returns 1 if the bits are different (one is 0, one is 1).
* ~ (Bitwise NOT / Complement): Inverts all the bits of a single operand (flips 0s to 1s and vice versa).
* << (Left Shift): Shifts bits to the left, padding the right side with zeros (effectively multiplies by powers of 2).
* >> (Right Shift): Shifts bits to the right (effectively divides by powers of 2).
